# 数值工具箱

需要 Python 3。在项目目录运行：

```sh
python3 server.py
```

如需使用其他端口，可运行 `python3 server.py --port 8001`，或设置环境变量 `PORT=8001`；`--port` 优先。服务监听本机回环地址。

打开 http://127.0.0.1:8000，进入股价涨跌幅计算器。输入股票名称或代码（例如 `贵州`、`腾讯`、`600000`、`00700`、`AAPL`），从候选列表选择 A 股、港股或美股，获取价格。按 Ctrl+C 停止服务。

名称搜索和行情默认使用新浪财经；新浪请求失败时会自动尝试腾讯行情，并在页面提示。也可手动选择腾讯行情或 Yahoo Finance。Yahoo 的中文名称搜索覆盖有限，建议输入英文名称或代码，暂不支持北交所。

点击“检测数据源”可分别测试各来源的搜索和 AAPL 报价，并显示最近检测时间；检测结果不代表所有股票或市场均可用。行情可能延迟，休市时显示最近价格。接口可能变化或限制访问，个别证券可能仅在某个来源可用。价格和计算结果仅供参考，其他计算可离线使用。

期权收益计算器位于首页工具导航，也可直接打开 `#options`。可手动输入合约参数，或配置行情后搜索美股并选择合约。到期前价格为模型估算，实际交易还会受到波动率、价差、费用、提前行权等因素影响。

期权合约查询默认使用 Alpaca Indicative，支持美股和 ETF 的标准 100 股期权。注册 Alpaca 账户并创建模拟账户 API 密钥，在项目目录运行以下命令，按提示输入密钥：

```sh
python3 configure_alpaca.py
python3 server.py
```

配置程序将密钥保存在项目目录的 `.alpaca-config.json`，仅当前用户可读写，且已排除在 Git 版本控制外。重新运行配置程序可更新密钥。环境变量 `ALPACA_API_KEY`、`ALPACA_API_SECRET`、`ALPACA_ENV` 优先于文件；默认使用模拟账户，正式账户需设 `ALPACA_ENV=live`。服务器部署时，可将这些变量放入 `/etc/stock-tools.env`（每行一个 `变量名=值`），将文件权限设为仅 root 可读，然后重启 `stock-tools` 服务。密钥不要放入网页或提交到版本库。

Alpaca Indicative 的报价经过调整，不是实际 OPRA 报价；成交数据延迟约 15 分钟。行情和隐含波动率可能缺失，缺失时可手动输入。价格、隐含波动率与计算结果仅供参考。

期权链按到期日和行权价排列看涨、看跌合约。选择要填入的头寸及买卖方向，点击表中任一合约即可填入；支持继续添加头寸。缺失的行情显示为 `—`。
