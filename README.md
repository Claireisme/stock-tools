# 数值工具箱

需要 Python 3。在项目目录运行：

```sh
python3 server.py
```

如需使用其他端口，可运行 `python3 server.py --port 8001`，或设置环境变量 `PORT=8001`；`--port` 优先。服务监听本机回环地址。

打开 http://127.0.0.1:8000，进入股价涨跌幅计算器。输入股票名称或代码（例如 `贵州`、`腾讯`、`600000`、`00700`、`AAPL`），从候选列表选择 A 股、港股或美股，获取价格。按 Ctrl+C 停止服务。

名称搜索和行情默认使用新浪财经；新浪请求失败时会自动尝试腾讯行情，并在页面提示。也可手动选择腾讯行情或 Yahoo Finance。Yahoo 的中文名称搜索覆盖有限，建议输入英文名称或代码，暂不支持北交所。

点击“检测数据源”可分别测试各来源的搜索和 AAPL 报价，并显示最近检测时间；检测结果不代表所有股票或市场均可用。行情可能延迟，休市时显示最近价格。接口可能变化或限制访问，个别证券可能仅在某个来源可用。价格和计算结果仅供参考，其他计算可离线使用。

期权收益计算器位于首页工具导航，也可直接打开 `#options`。可手动输入合约参数，或配置行情后搜索美股并选择合约。到期前价格为模型估算，实际交易还会受到波动率、价差、费用、提前行权等因素影响。

期权合约查询默认使用 Alpaca Indicative，支持美股和 ETF 的标准 100 股期权。注册 Alpaca 账户并创建模拟账户 API 密钥，在项目目录运行以下命令，按提示输入密钥：

```sh
python3 configure_alpaca.py
python3 server.py
```

配置程序将密钥保存在项目目录的 `.alpaca-config.json`，仅当前用户可读写，且已排除在 Git 版本控制外。重新运行配置程序可更新密钥。环境变量 `ALPACA_API_KEY`、`ALPACA_API_SECRET`、`ALPACA_ENV` 优先于文件；默认使用模拟账户，正式账户需设 `ALPACA_ENV=live`。服务器部署时，可将这些变量放入 `/etc/stock-tools.env`（每行一个 `变量名=值`），将文件权限设为仅 root 可读，然后重启 `stock-tools` 服务。密钥不要放入网页或提交到版本库。

Alpaca Indicative 的报价经过调整，不是实际 OPRA 报价；成交数据延迟约 15 分钟。行情和隐含波动率可能缺失，缺失时可手动输入。价格、隐含波动率与计算结果仅供参考。

期权链按到期日和行权价排列看涨、看跌合约。选择要填入的头寸及买卖方向，点击表中任一合约即可填入；支持继续添加头寸。缺失的行情显示为 `—`。

投资者披露追踪位于 `#investors`。首次运行需要安装 ARK 官方 XLS 文件解析依赖：

```sh
python3 -m pip install 'xlrd>=2.0.1,<3' 'pypdf>=4,<7'
export SEC_USER_AGENT='Your application contact@example.com'
python3 server.py
```

SEC 要求 User-Agent 包含应用名称和有效联系邮箱。本机配置存于 `.sec-config.json`；SEC_USER_AGENT 环境变量优先。服务在后台检查已核验 CIK 的 Form 4、Schedule 13D 和 13F，Form 4 初次回溯最近 180 天；ARK 交易来自基金每日通知。13F 比较连续季度的申报持仓，并非交易记录；首次运行及回填可能需要较长时间。众议院 PTR 依据姓名、州区和任期匹配官方索引，每次最多回填 40 份；扫描件没有 OCR，仅显示申报链接。身份映射适用于 2025–2026 年，之后须重新核验。参议院 PTR 不在当前监控范围内。10b5-1 标记属于整份 Form 4，不代表其中每笔交易均受该计划约束。首次运行会在项目目录创建 `investor_events.sqlite3`；可通过 `INVESTOR_DB_PATH` 指定可写路径。服务器部署时，将 `SEC_USER_AGENT` 写入 `/etc/stock-tools.env`，并为服务使用的 Python 安装上述依赖。数据来自公开披露，存在延迟和覆盖范围限制。

在追踪页面点击“启用浏览器提醒”并允许通知，页面保持打开时每分钟检查新增事件；关闭页面或浏览器后不会推送。首次启用从当前记录开始。公开披露存在延迟，PTR 数额为区间，使用时应遵守来源的用途限制。

在持仓追踪页面点击关注名单或事件中的人物，可打开详情页，按年份、方向、证券和 ARK 基金筛选；统计涵盖本地已采集数据，交易明细可分页查看。议员金额是披露区间的合计；ARK 明细是基金交易；13F 显示季度末持仓变化。详情页不根据不完整的披露推算实时持仓、净资产或收益。

ARK 详情页提供 13 只基金的官方每日持仓快照，显示数量、市值和基金权重；ARKY 的官方文件格式不同且不含持仓日期，暂未接入。快照从启用时开始保存在本机；至少采集到两个不同日期后才能比较变化。相邻已采集快照之间可能间隔多个交易日，数量变化也可能来自基金申赎或公司行动，不等同于实际买卖。

在 ARK 基金持仓表中点击证券，可查看已采集的持仓数量或基金占比与历史股价。持仓只显示实际快照，未采集日期不补值；当前只有一份快照的证券显示一个点。股价使用 Alpaca IEX 未复权日收盘价，属于单一交易所数据；代码与证券标识无法核验、无行情或未配置 Alpaca 时，图表只显示持仓。
